# brewnet

Brew identifiers and net tokens for idempotent workflows.

**Site:** https://theworker02.github.io/brewnet/

## Install / run

```bash
git clone https://github.com/theworker02/brewnet.git
cd brewnet
node src/cli.js
node --test
```
